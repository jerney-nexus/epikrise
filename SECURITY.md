# Security Policy

## Supported Versions

Epikrise has not published a versioned release yet. Until the first release,
security fixes target the latest code on `main`. After releases begin, only the
latest published release is supported; older releases may not receive security
fixes.

## Reporting a Vulnerability

Report vulnerabilities privately through [GitHub's private vulnerability
reporting form](https://github.com/jerney-nexus/epikrise/security/advisories/new).
Do not open a public issue, discussion, or pull request, or disclose the
vulnerability publicly before maintainers have had a reasonable opportunity to
investigate and prepare a fix.

Do not include real patient data, clinical text, credentials, API keys, or other
secrets in a report. Include the affected version or commit, platform, impact,
and reproduction steps. Use only synthetic, non-sensitive examples.
