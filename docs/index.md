# Epikrise

Epikrise is a local-only desktop drafting aid. It turns clinical material that you supply (text, documents, images and web pages) into a structured draft for review and manual use in your clinic information system.

Epikrise does not anonymize input. Remove identifying details before use. It is a drafting aid, not a medical device and not a diagnostic tool. The responsible clinician must review every generated text before use.

## Download

Installers and release notes are published on [GitHub Releases](https://github.com/jerney-nexus/epikrise/releases).

## Privacy

- No hosted backend, telemetry or account. Input is processed on your device, except for requests sent to the model endpoint you configure.
- Case content is held in memory and is not saved as history.
- API keys are stored in the operating system keychain.

The full privacy policy is available in [English](https://epikrise.jerney.nexus/privacy-policy/en/), [Deutsch](https://epikrise.jerney.nexus/privacy-policy/de/), [Français](https://epikrise.jerney.nexus/privacy-policy/fr/), [Italiano](https://epikrise.jerney.nexus/privacy-policy/it/) and [Español](https://epikrise.jerney.nexus/privacy-policy/es/).
